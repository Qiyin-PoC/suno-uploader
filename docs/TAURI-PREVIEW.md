# Tauri 轻量验证：结果与迁移门槛

日期：2026-09-08。状态：本机技术验证，不能出售或作为全平台正式版。

## 当前判断

Tauri 值得作为轻量版方向继续验证：当前方案能把 Python 音频引擎冻结进安装包，
不必在每台用户电脑上安装 Python/Node。迁移成本主要在原生窗口、账号状态、后台任务、
更新和不同操作系统的兼容性，而不是重写音频算法。

本次保留 Electron 原有代码，另建 `tauri-preview`。新界面覆盖单文件稳定上传、下载、
歌词工具、上传历史与期音账号登录；并不是把原有全部 Electron 功能原样搬完。

## 已发现并处理的问题

- 更新插件没有配置时导致整个应用启动崩溃：补齐空配置，检查更新明确报告未配置。
- WebKit 原生 HTML modal dialog 的账号内容在本机辅助功能树中不可访问：换成可访问的覆盖层。
- Node 在 ARM 模式、Rust/Python 在 Intel 模式，打包工具误标 ARM 文件名：按 Rust 实际架构打包并核验 runtime。
- 通用 FFmpeg 下载包带 `--enable-nonfree`：拒绝该二进制，改为从官方源码构建精简音频版。
- 本机 Python/FFmpeg 实际最低要求 macOS 26：安装器标明 26.0，不能声称支持旧 Mac。
- 原 Python 后端存在异常退出码为 0 的路径：宿主需要明确成功事件和成功退出码同时满足。

## 打包与运行

本机：Apple Silicon，macOS 26.6.2。当前应用与 Python worker 均为 x86_64，通过 Rosetta 运行。

- Rust/Tauri 宿主 + 系统 WKWebView。
- 冻结的 Python 3.14.6、NumPy、Requests、Pinyin、WebSocket 等依赖。
- FFmpeg 8.0.1 音频构建，静态 LAME，无 GPL/nonfree 配置；二进制约 2.9 MiB。
- 独立 bundle ID / 数据目录，不读取 Electron 的商业账号凭据。
- 测试服务固定为本机 `127.0.0.1:18870`；不能发给用户后期望其自动连上商业后端。
- 商业账号凭据只放在 Rust 内存，每次操作重新向服务器检查权限；重启需重新登录。

## 已完成的验证

- 现有 Python 回归：14 项通过。
- 现有 Node 回归：14 项通过，含本机真实 HTTP 授权服务。
- 新 Rust 定向测试：4 项通过，覆盖服务地址限制、参数限制、敏感字段过滤、明确成功判定。
- 冻结引擎在 `PATH=/usr/bin:/bin` 下通过自检：12 秒合成音频拆成 3 段、变速、中文拼音、韩语转换。
- 独立引擎真实下载 Suno 歌曲并转成 MP3，返回明确 `succeeded`，输出文件已生成。
- Native Tauri 窗口可打开；未登录点歌词处理明确拒绝；原生选文件后路径与歌曲名正确回填。

- 最终 DMG 挂载校验成功；复制到项目外的 `/tmp/qiyin-tauri-dmg-install` 后启动成功，并再次通过独立引擎自检。这里只验证本机搬移安装，未替代干净机器测试。
- 窗口内真实连接本机账号服务，登录成功；不重启撤销授权后，下一次操作立即显示“尚未开通或授权已到期”。测试后已恢复测试授权。

- 上传记录刷新得到真实空列表；选文件对话框能选择生成的测试 WAV 并回填歌曲名。
- Suno 登录流程进入等待用户登录状态。点击停止后恢复可用，进程检查确认没有 worker 残留。
- 从最终 DMG 启动，运行登录任务后使用应用退出（Cmd+Q）；worker PID 21811 与主程序均退出。
- 重启明确要求重新登录，没有把只存在内存中的登录状态误报为已保存。
- 检查更新明确提示服务和签名公钥未配置。
- 截图服务随后恢复，已检查上传、下载、记录页面的窗口布局；并修复任务栏和记录区域的可访问性。

## 实测体积

| 产物 | 大小 | 口径 |
|---|---:|---|
| 最终 DMG | 31,116,247 字节（31.12 MB / 29.68 MiB） | 压缩安装镜像，x86_64 |
| 最终 .app | 68,540,605 字节（68.54 MB / 65.37 MiB） | 逐文件逻辑大小 |
| .app 本机磁盘占用 | 67,496 KiB（65.91 MiB） | `du -sk` |
| 原 Electron 引擎目录 | 314,672 KiB（307.30 MiB） | 仅 Electron 引擎，不是完整商业安装包；ARM 版本 |

这不是完全同功能、同架构的正式包对比，不能据此声称最终商业版固定减少某个百分比。
但它证明了含 Python 和 FFmpeg 的轻量包可以控制在几十 MB，而不是仅有界面的空壳。
源码仓库内的 Rust 编译缓存约 GB 级是开发机成本，不随安装包分发。

## 仍未通过的发布门槛

- 真实 Suno 账号登录与上传成功尚未验证，需要用户完成其账号登录。
- Windows、Linux、原生 Apple Silicon、旧版 macOS、无开发环境的干净机器尚未测试。
- 未签名、未公证；不代表新用户双击安装不会遇到系统拦截。
- 自动更新仅接入插件并正确显示未配置；更新下载/验签/安装/重启/保留数据未实现验收。
- 持久批量队列、断点续传、多 Suno 账号切换、设备管理/支付界面尚未迁移。
- Suno 凭据仍使用原引擎的本地明文存储，目录权限收紧不能代替系统钥匙串。
- 正式分发前仍需完整提供 FFmpeg/LAME 对应源码、构建说明及第三方许可；本次不作合规完成声明。

## 综合成本判断

| 维度 | 保留 Electron | Tauri 路线 |
|---|---|---|
| 近期交付 | 已有功能迁移最少 | 先补齐账号/队列/更新及平台适配 |
| 用户安装 | 通常自带浏览器内核，体积大 | 体积明显下降；Windows WebView2 与 Mac 运行时仍需处理 |
| 后端运维 | 账号、订单、回调、备份、监控照常需要 | 同样需要，不因换壳消失 |
| 更新运维 | 可复用成熟 Electron 更新链路，但本项目尚未配置 | 需配置签名公钥、发布源与更新流程并验收 |
| 多端回归 | 自带一致 Chromium，仍需测 OS 差异 | Windows/macOS/Linux 使用不同内核，增加界面兼容回归 |
| 长期带宽 | 包体通常更大 | 更小的下载包可降低分发带宽 |

建议：继续以 Tauri 为轻量正式版候选，但先通过“真实上传 + Windows 干净安装 + 签名更新”
三个门槛再替换 Electron。目前已有体积可行性的实证，还没有足够证据宣布全功能迁移完成。

### 批量任务

上传页面可通过系统文件选择器多选最多 100 个音频文件，多选时每首以文件名命名。下载页面每行粘贴一个 Suno 歌曲链接，选择统一格式与保存目录；重复的相同链接自动去重，最多 100 首。两种队列均逐项启动 worker，每项重新进行服务器授权，避免一次授权覆盖整个长队列。

每首显示等待、处理、成功、失败或停止状态。失败项可单独重试；停止会终止当前任务并保留后续待处理项，“继续未完成”可继续。已成功条目不会被重试按钮重新执行。队列只保留在本次应用会话中，退出应用不会自动续跑。对于上传中途停止或网络断开，重试前应核对 Suno 曲库，远端可能已收到音频。
